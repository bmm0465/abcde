# 01. 실행 가이드

로컬에서 띄우고, 새 Supabase 프로젝트를 연결하고, Vercel 에 올리는 순서.

## 1. 로컬 실행 (Supabase 없이)

```bash
npm install
npm run dev
```

http://localhost:3000 — 허브 화면(프로젝트·기록·소개)은 Supabase 없이도 열린다. 상단 바에 "인증 미설정" 이 보이면 정상이다.

## 2. 새 Supabase 프로젝트

1. https://supabase.com/dashboard → **New project**. 이름은 자유(예: `abcde`), 리전은 `Northeast Asia (Seoul)`, DB 비밀번호는 비밀번호 관리자에 저장.
2. **Project Settings → API** 에서 세 값을 복사한다.
   - Project URL → `NEXT_PUBLIC_SUPABASE_URL`
   - Publishable key(`sb_publishable_…`) → `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY` (구형 프로젝트는 anon key → `NEXT_PUBLIC_SUPABASE_ANON_KEY`)
   - Secret / service_role key → `SUPABASE_SERVICE_ROLE_KEY` (**서버 전용. 절대 브라우저·저장소에 두지 않는다**)
3. `.env.example` 을 복사해 `.env.local` 을 만들고 값을 채운다.

### 2.1 인증 설정 (Authentication → 왼쪽 메뉴)

| 항목 | 값 |
|---|---|
| **Sign In / Providers → Email** | 켜기. **Confirm email** 켜기(가입 시 인증 메일). |
| **URL Configuration → Site URL** | 운영 도메인(예: `https://abcde-projects.vercel.app`). 로컬 개발 중에는 `http://localhost:3000` |
| **URL Configuration → Redirect URLs** | `http://localhost:3000/auth/callback`, `https://<운영 도메인>/auth/callback`, 그리고 Vercel 프리뷰를 쓰면 `https://*-<팀>.vercel.app/auth/callback` |
| **Emails → Templates** | 기본 템플릿도 동작한다. 한국어로 바꾸려면 Confirm signup / Reset password 두 개만 손보면 된다. |
| **Rate Limits** | 기본값 유지. 무료 플랜의 내장 메일은 시간당 소량이라, 사용자가 늘면 **SMTP(Resend 등)** 를 연결한다. |

### 2.2 마이그레이션 적용

방법 A — SQL 편집기(가장 단순):
1. Dashboard → **SQL Editor** → New query.
2. `supabase/migrations/20260912000000_hub_core.sql` 내용을 붙여 넣고 Run.
3. 이후 파일도 파일명 순서대로 같은 방식.

방법 B — CLI(반복 작업에 유리):
```bash
npx supabase login                       # 브라우저에서 토큰 발급
npx supabase link --project-ref <ref>    # ref 는 Project Settings → General
npm run db:push                          # supabase/migrations 를 순서대로 적용
```

### 2.3 관리자 지정

```bash
npm run admin:promote -- you@example.com
```

이 주소를 관리자 목록에 넣는다. **그 뒤 사이트에서 이 주소로 가입**하면 즉시 관리자(승인됨)가 된다. 이미 가입했다면 바로 승격된다.

### 2.4 확인

1. `npm run dev` → `/signup` 에서 관리자 주소로 가입 → 인증 메일 링크 → `/account` 에 "관리자" 배지.
2. 다른 주소로 가입 → `/pending` 화면 → 관리자로 `/admin` 에서 승인 → 그 계정의 `/account` 에 "교사".
3. `/admin/usage` 는 아직 비어 있다(앱 이식 후 기록이 쌓인다).

## 2.5 AIEEWA 쓰기

문항 생성과 채점에는 OpenAI 키가 필요합니다. `.env.local` 과 Vercel 환경 변수에 `OPENAI_API_KEY` 를 넣으세요.

### RAG 코퍼스 넣기 (선택이지만 권장)

코퍼스가 비어 있어도 문항은 만들어집니다. 다만 교과서·성취기준에 근거하지 않습니다.

1. 저장소 루트에 `corpus` 폴더를 만들고 교육과정 자료를 넣습니다. `.pdf` `.txt` `.md` 를 읽습니다.
   - 이 폴더는 `.gitignore` 에 있습니다. **원본은 절대 커밋되지 않습니다.**
   - 서버에는 텍스트 청크와 벡터만 올라갑니다. PDF 파일 자체는 올라가지 않습니다.
2. 적재합니다.

```bash
npm run aieewa:seed
```

같은 파일을 다시 넣으면 그 문서의 청크만 지우고 다시 만듭니다. 파일 이름이 곧 문서 id 라, 이름을 바꾸면 새 문서가 됩니다.

스캔한 PDF(그림으로만 된 것)는 텍스트가 없어 건너뜁니다. OCR 을 먼저 돌려야 합니다.

### 비용 감각

`AIEEWA_MODEL` 기본값은 `gpt-4o` 입니다. 대략 문항 한 건 생성에 0.05~0.15달러, 답안 한 건 채점에 기본 채점은 0.01~0.03달러, 근거 채점(AAS)은 검증과 재채점까지 해서 0.03~0.10달러쯤 듭니다. 사용자별 월 한도는 관리자 화면에서 조정합니다. 더 싼 모델로 바꾸려면 `AIEEWA_MODEL` 을 설정하고 `src/lib/usage/pricing.ts` 의 단가표에 그 모델이 있는지 확인하세요.

### 함수 실행 시간

생성과 채점 라우트는 `maxDuration = 60` 입니다. Vercel Hobby 의 상한이 60초입니다. Pro 라면 `src/app/api/aieewa/*/route.ts` 에서 300 까지 올릴 수 있습니다.

## 3. Vercel 배포

1. GitHub 에 저장소를 올린다(공개). `npm run check:secrets` 가 통과하는지 먼저 본다.
2. https://vercel.com/new → 저장소 import. Framework 는 Next.js 자동 인식.
3. **Environment Variables** 에 `.env.example` 의 키를 넣는다. `NEXT_PUBLIC_SITE_URL` 은 운영 도메인.
4. Deploy. 끝나면 Supabase **Site URL / Redirect URLs** 를 운영 도메인으로 맞춘다.
5. GitHub 에 푸시할 때마다 자동 배포된다. PR 은 프리뷰 URL 이 생긴다.

## 4. 환경 변수 요약

| 키 | 어디서 | 노출 |
|---|---|---|
| `NEXT_PUBLIC_SITE_URL` | 운영 도메인 | 공개 |
| `NEXT_PUBLIC_SUPABASE_URL` | Supabase API 설정 | 공개 |
| `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY` (또는 `_ANON_KEY`) | Supabase API 설정 | 공개(RLS 가 지킨다) |
| `SUPABASE_SERVICE_ROLE_KEY` | Supabase API 설정 | **서버 전용** |
| `DEFAULT_MONTHLY_BUDGET_USD` | 임의(기본 5) | 서버 |
| `RATE_LIMIT_PER_MINUTE` | 임의(기본 20) | 서버 |
| `OPENAI_API_KEY` 등 | 각 제공자 | **서버 전용**, 앱 이식 단계에서 |

## 5. 자주 막히는 곳

- **가입 메일이 안 온다** → Authentication → Logs 확인. 무료 플랜 내장 메일은 시간당 한도가 작다. SMTP 연결.
- **인증 링크를 누르면 로그인 화면으로 돌아온다** → Redirect URLs 에 `/auth/callback` 이 정확히 있는지, Site URL 이 현재 도메인인지 확인.
- **/admin 이 404** → 그 계정이 admin/approved 가 아니다. `npm run admin:promote` 후 다시 로그인.
- **사용량이 "불러오지 못했습니다"** → `SUPABASE_SERVICE_ROLE_KEY` 가 없다.
- **빌드에서 `bg-blue-500` 같은 클래스가 깨진다** → 의도된 것. `globals.css` 의 토큰을 쓴다.
