# 03. 디자인 시스템 — 교실의 연구 노트

구현체: `src/app/globals.css`(토큰·조판), `src/components/ui/*`(부품), `eslint.config.mjs`(방어선).

## 1. 왜 이렇게 만드는가

이 사이트의 이름은 **A Better Class: Data & Education** 이다. 교실에서 시작해 데이터로 답을 찾고, 그 과정을 글로 남기는 곳. 그래서 참조 대상은 SaaS 랜딩페이지가 아니라 **학급 일지, 연구 노트, 학술지의 조판**이다.

"AI 로 급조한 사이트"는 반복되는 시각적 서명으로 판별된다: 보라→파랑 그라데이션, 히어로 + 3열 카드, 유리 카드, 과한 라운드, 두꺼운 그림자, 제목 이모지, 채도 높은 상태색, 등장 애니메이션, 그리고 어디서나 같은 산세리프. 그 반대편에 서면 된다 — 종이, 잉크, 명조, 괘선, 도장.

## 2. 세 가지 재료

| 재료 | 뜻 | 쓰임 |
|---|---|---|
| **흰 종이와 잉크** | 바탕은 흰 종이(`bg #ffffff`), 글자는 잉크(`text #1c1b18`, 순흑 아님) | 모든 화면 |
| **칠판 녹색** | 액센트 단 하나(`accent #24593f`). 어두운 화면에서는 종이가 칠판이 되고 글자는 분필이 된다 | 링크, 선택 상태, 주 버튼 호버 |
| **붉은 연필** | 표시(`mark #b7412b`). 교사가 채점하듯 아주 조금만 | 워드마크의 마침표, 태그라인 머리글자, 현재 메뉴 밑줄, 섹션 번호 |

바탕은 흰색이다. 2026-09-13 에 베이지(`#f4efe6`)에서 바꿨다. 이유는 셋이다.

1. 이 사이트의 본문은 **차트와 스크린샷**이다. 데이터 시각화 산출물은 흰 바탕을 전제로 만들어지고, 베이지 위에 놓으면 그림만 하얗게 떠 보인다.
2. 색이 든 바탕은 그 자체로 "테마"로 읽힌다. 정체성은 바탕색이 아니라 **활자와 괘선**이 진다.
3. 종이 은유는 흰색에서 더 정확하다. 실제 학습지·보고서는 흰 종이다.

대신 회색 계열(`sunken` `inset` `line`)에는 미세한 온기를 남겼다. 순수 중성 회색은 임상적으로 보이고, 녹색·붉은색 액센트와 어울리지 않는다.

**`bg` 와 `surface` 가 같은 흰색인 것은 의도다.** 판(panel)·입력칸은 채움이 아니라 테두리로 선다. 눌린 면이 필요한 곳(표 머리, 코드 블록, 호버)은 `sunken` 을 쓴다.

## 3. 활자 세 벌

| 역할 | 글꼴 | 어디에 |
|---|---|---|
| 제목 | **Noto Serif KR** (명조, 가변) | h1~h3, 기록 제목, 워드마크 |
| 본문·UI | **IBM Plex Sans KR** 400/500/600 | 본문, 버튼, 폼, 표 셀 |
| 기록 | **IBM Plex Mono** 400/500 | 날짜, 숫자, 표 머리, 라벨(`label-mono`), 배지 |

- 본문 15px / 행간 1.75, `word-break: keep-all`. 한글 굵기는 400/500/600, 명조 제목만 700 까지.
- 크기: caption 12 · sm 13 · base 15 · lg 17 · h2 20 · display 26 · title 32 · hero 44(첫 화면 한 곳).
- 글꼴은 `next/font/google` 로 빌드 때 받아 같은 도메인에서 낸다. CSP `font-src 'self'`.

## 4. 괘선이 위계다

- **굵은 선(`rule-t`, 2px 잉크)** 은 표와 목록의 머리, 화면 제목 아래, 판권면 위에 하나씩.
- **가는 선(`hairline-b`, 1px)** 은 행 사이, 섹션 제목 아래.
- 세로선 없음. 줄무늬 없음. 정적 요소에 그림자 없음. 카드 대신 행과 판(panel).
- 모서리 2 / 3 / 6px. 인쇄물처럼 날카롭게.
- 첫 화면 리드 블록에만 모눈종이(`paper-grid`). 다른 곳엔 쓰지 않는다.

## 5. 워드마크

```
ABCDE.          ← 명조 600, 자간 0.08em, 마침표만 붉은 연필
A Better Class: Data & Education   ← 명조, 머리글자 A·B·C·D·E 를 붉은 연필로
```

그림·아이콘 마크는 없다. 파비콘은 종이 위의 명조 "A" 와 붉은 점 하나(`src/app/icon.svg`).

## 6. 부품 규격

- **버튼**: Primary 는 잉크로 채움(호버 시 녹색), 화면당 1개. Secondary 는 잉크 테두리. 로딩은 스피너 대신 라벨 교체 + disabled.
- **배지**: 도장처럼 — 모노 11px, 대문자, 1px 테두리, 최대 5종 톤.
- **표**: `rule-t` + 머리 아래 1px strong + 행 1px. 머리는 모노 라벨. 숫자는 우측 정렬 모노.
- **목록(장부·목차)**: 위에 굵은 선, 행마다 가는 선. 연도·날짜는 모노, 기록 제목은 명조.
- **폼**: 라벨 위, "(선택)" 표기, 도움말 12px. 입력칸은 종이(surface) 바탕에 잉크 테두리.
- **상태**: 빈 상태 = 점선 상자 + 1줄 + 행동 1개. 오류·알림 = 왼쪽 3px 색 띠. 로딩 = 행 높이 플레이스홀더(shimmer 금지).
- **섹션**: `Section number="01"` — 번호는 모노, 붉은 연필.

## 7. 린트가 막는 것

Tailwind 기본 색 이름, `rounded-xl` 이상, `shadow-sm~2xl`, `backdrop-blur`, `bg-gradient-*`, `animate-*`. 이식된 레거시 앱(`src/app/(apps)/**`)만 1차 예외.

## 8. 문구

경어체. 감탄사·이모지 없음. 동작 라벨은 동사. AI 결과는 "검토 필요"·"추정값" 으로 표기. 금지: "완벽한", "놀라운", "혁신적인", ✨, 🚀.

## 9. 데이터 시각화

선·막대·점·스파크라인만. 도넛·파이·3D·레이더·게이지 금지. 계열 색은 `viz-1..4`(녹색·붉은 연필·황토·잉크 회색). 축 항상 표시, 눈금선은 가로만. 차트 아래 캡션 1줄. 논문 그림으로 그대로 옮길 수 있어야 한다.
